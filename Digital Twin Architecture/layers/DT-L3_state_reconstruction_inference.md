# DT-L3 — Building State Reconstruction & Inference

## Status
Working scaffold — not yet analyzed in detail.

## Core question
How can observable data be converted into a probabilistic reconstruction of the hidden building/material state?

## Candidate outputs
- archetype
- structural system
- construction period
- material composition
- component assemblies
- material intensity
- total stock
- component age
- renovation state
- condition / quality
- remaining service life
- potentially recoverable stock

## Uncertainty analysis
Focus on inference uncertainty, archetype assignment, hidden components, proxy use, transferability, model uncertainty, calibration and validation.


## Output contract to Material Decision Profile

The principal DT-L3 output is a **probabilistic material inventory**:

Building → Components → Material batches → type / quantity distribution / condition / quality / contamination / age-state / uncertainty.

Material batches with different condition or circularity potential should not be collapsed prematurely.
