# DT-L2 — Identity, Integration & Context

## Status
Working scaffold — not yet analyzed in detail.

## Core question
How should heterogeneous data be linked to the same building/material entities while preserving spatial, temporal and provenance context?

## Candidate capabilities
- persistent Building ID
- entity resolution
- schema harmonization
- provenance
- versioning
- spatialization
- regionalization
- spatial grain / coverage management
- scale transition rules
- temporal alignment
- interoperability across S1–S5

## Uncertainty analysis
Focus on identity mismatch, spatial mismatch, temporal mismatch, contextual representativeness and information loss during harmonization or aggregation.
