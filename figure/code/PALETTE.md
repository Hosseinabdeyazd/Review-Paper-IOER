# Unified academic palette

- Broad: #4C78A8
- Uncertainty: #72B7B2
- Highlight / amplified: #9D755D
- Neutral / masked-lost: #7F7F7F
- Soft neutral / no verified propagation: #B8B8B8
- Grid: #D9D9D9
- Very light / unassessed: #ECECEC
- Text: #2F2F2F

## Semantic use for Figures 05-08

- Source/type figures use the uncertainty teal.
- Method figures use the manuscript blue.
- Propagation outcomes use the same muted palette semantically:
  - Preserved: uncertainty teal
  - Transformed: manuscript blue
  - Amplified: muted brown
  - Masked/lost: neutral gray
  - Legitimately reduced: soft neutral
  - Unassessed: very light gray
- Interface-comparison figures use uncertainty teal for verified/partial propagation and soft neutral for no verified propagation/unassessed.
