# Global mapping pilot

This folder contains the geography coding used for the first global transition-evidence map.

## Mapping rule

Geography is coded from the country of application or empirical study area, not author affiliation.

Multi-country empirical studies use fractional counting (1/n across countries). Global, review, synthetic, or otherwise non-territorial studies are retained in the CSV but are not forced onto a country.

The current map is a pilot based on the uncertainty-transition candidate set for S1→S2 and S2→S3. It should not be interpreted as a final map of the screened literature.

## Figure encoding

- blue: S1→S2 candidate transition evidence
- teal: S2→S3 candidate transition evidence
- brown star: candidate spanning S1→S2→S3
- symbol size: weighted transition-evidence count

The map is generated by `figure/code/make_Figure_03_Global_Transition_Evidence_Map.py`.


## Full-text uncertainty-handoff maturity audit

A stronger geographic analysis is now built from the current full-text transition-candidate set rather than simple candidate counts.

### Handoff maturity scale

- H1 — local uncertainty characterization, validation, or sensitivity only; no downstream uncertainty state is propagated
- H2 — propagation-ready uncertainty representation, but downstream propagation is not performed in the same study
- H3 — partial propagation: selected uncertainties or model-form variations reach downstream outputs, but the full interface is not probabilistically propagated
- H4 — quantitative interface propagation using distributions, sampling, bootstrap, Monte Carlo, confidence intervals, or equivalent downstream uncertainty transfer
- H5 — uncertainty is propagated to decision robustness, ranking stability, regret, or an equivalent decision-level robustness analysis

Sensitivity analysis alone is not classified as uncertainty propagation. Prediction accuracy metrics such as RMSE, MAPE, R², F1, or classifier accuracy are also not treated as propagation unless their uncertainty state is transferred downstream.

### Geographic rule

Geography continues to use country of application, not author affiliation. Multi-country studies are fractionally allocated using 1/n. Global, review, synthetic, and non-territorial studies remain in the paper-level audit but are not forced onto a country.

### Current pilot result

The current audit suggests a strong maturity asymmetry between adjacent interfaces: S1→S2 is dominated by H1 studies, whereas S2→S3 contains substantially more H3–H4 studies. No H5 study is identified in the current candidate set. This is a pre-screening full-text audit and must not yet be interpreted as the final global distribution of the literature.

One S1→S2 paper (DOI 10.1021/acs.est.5c03058) is coded provisionally from its supplied Supporting Information because the main article was not present in the provided files. One S2→S3 candidate (DOI 10.1177/0734242X07079183) remains unverified because its full text was not available.
