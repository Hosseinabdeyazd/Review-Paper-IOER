# Global mapping pilot

This folder contains the geography coding used for the first global transition-evidence map.

## Mapping rule

Geography is coded from the country of application or empirical study area, not author affiliation.

Multi-country empirical studies use fractional counting (1/n across countries). Global, review, synthetic, or otherwise non-territorial studies are retained in the CSV but are not forced onto a country.

The current map is a pilot based on the uncertainty-transition candidate set for S1→S2 and S2→S3. It should not be interpreted as a final map of the screened literature.

## Figure encoding

- blue: S1→S2 candidate transition evidence
- teal: S2→S3 candidate transition evidence
- brown star: candidate spanning S1→S2→S3
- symbol size: weighted transition-evidence count

The map is generated by `figure/code/make_Figure_03_Global_Transition_Evidence_Map.py`.
